# হিসাবের খাতা — Android অ্যাপ

অফলাইনে চলে, বিজ্ঞাপন নেই। সব হিসাব শুধু আপনার ফোনেই থাকে।

## APK বানানোর সহজ উপায় (কম্পিউটার লাগবে না) — GitHub

1. https://github.com এ ফ্রি একাউন্ট খুলুন।
2. উপরে **+ → New repository** → নাম দিন `HisabKhata` → **Create repository**।
3. **uploading an existing file** লিংকে চাপুন। জিপ খুলে ভেতরের সব ফাইল ও ফোল্ডার আপলোড করুন
   (`.github` ফোল্ডারটাও অবশ্যই আপলোড করবেন) → **Commit changes**।
4. উপরের **Actions** ট্যাবে যান। "Build APK" চলতে শুরু করবে (৩–৫ মিনিট)।
5. সবুজ ✓ হলে সেটাতে চাপুন → নিচে **Artifacts** থেকে `HisabKhata-APK` নামান।
6. জিপ খুলে `app-debug.apk` ফোনে ইনস্টল করুন
   (ফোন "অজানা উৎস থেকে ইনস্টল" অনুমতি চাইলে দিন)।

## Android Studio দিয়ে (কম্পিউটার থাকলে)

1. Android Studio ইনস্টল করুন → **Open** → এই `HisabKhata` ফোল্ডার খুলুন।
2. Gradle সিঙ্ক শেষ হলে মেনু থেকে **Build → Build APK(s)**।
3. তৈরি হওয়া APK থাকবে `app/build/outputs/apk/debug/app-debug.apk`-এ।

## ব্যাকআপ

অ্যাপের "মাসগুলো" ট্যাবে **ব্যাকআপ পাঠান** চাপলে হিসাবের লেখা WhatsApp/ইমেইলে পাঠাতে পারবেন।
নতুন ফোনে **ব্যাকআপ ফেরত আনুন** চেপে সেই লেখা পেস্ট করলেই সব হিসাব ফিরে আসবে।
